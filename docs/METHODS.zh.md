# MedWear 分析引擎 — 方法学

本文描述真实模式与基准评测中使用的**透明、可复现**分析流水线。核心告警/异常检测不使用黑盒深度学习。

## 健康评分

日综合分（0–100）：

| 组成 | 权重 | 规则 |
|------|------|------|
| 步数 | 30% | `min(steps/10000, 1)` |
| 睡眠 | 25% | `min(totalSleepHours/8, 1)` |
| 静息心率 | 20% | 50–75 bpm → 1.0；<50 → 0.7；否则 0.5 |
| 血氧 | 15% | ≥95% → 1.0；≥90 → 0.6；否则 0.3 |
| HRV | 10% | `min(hrv/60, 1)` |

实现：`server/services/analyticsCore.js` → `computeDayScore()`

## 告警 {#alerts}

基于**目标日**的阈值规则：

- **心率偏高**：平均 HR > `heartRateMax`（默认 100 bpm）
- **心率偏低**：平均 HR < `heartRateMin`（默认 50 bpm）
- **血氧偏低**：平均 SpO₂ < `spo2Min`（默认 93%）
- **活动量不足**：步数 > 0 且 < 3000

## 异常检测 {#anomalies}

14 天滑动窗口：

1. **心率尖峰**：≥3 次读数高于个人均值 + 2σ
2. **血氧事件**：≥2 次读数低于 93%

## 风险分层

由健康评分映射：

| 等级 | 分数 |
|------|------|
| 低 | ≥ 80 |
| 中 | 60–79 |
| 高 | < 60 |

## 趋势预测（真实模式）

启发式规则见 `server/health/analytics.js`：

- 近 7 天 vs 前 7 天静息心率上升 >5 bpm → 心血管趋势
- HRV 下降 >15% → 压力/疲劳
- ≥3 天步数 <4000 → 久坐风险
- 日步数骤降 >50% → 类感染/急性病模式
- 反复低血氧 → 呼吸系统标记
- 连续 3 天睡眠 <6h → 睡眠赤字

## 双模式架构

| 模式 | 数据 | AI |
|------|------|-----|
| 演示 | 合成临床模拟数据 | 规则引擎 |
| 真实 | Apple Health 导入 | 可选 OpenAI 等 + 分析核心 |

## 局限性

- 未在临床队列上验证
- Apple Health 导出缺少连续临床级波形
- 筛查类别为**健康管理导向**，非诊断结论
